the lab notebook but not yet traceable to a banked record (the thesis's own stated standard). All are
fixable with sentence-level edits; none require new core work.

### Ch4 — derivations (correct, but state the truncation/domain)

**S5. The argmin "exact" proof and the optical-depth derivation are written for the *full* Gaussian, but the renderer truncates at 3σ.** [verified] — `04:104–123` and the exactness proof `:196–209` use the
untruncated transmittance $e^{-\tau}$, while the code clamps the integration to `GAUSSIAN_DIAMETER_F`
(`primitive.h:282`) and clips the inverse-CDF. So the argmin is exact *for the rendered (3σ-truncated)
mixture*, not the ideal Gaussian — and this is the natural home for the +2×10⁻⁴ overlap residual that Ch5
attributes to "the argmin free-flight distribution".
Fix: state once (where the 3σ BVH bound is introduced) that τₖ, the collision draw, and the transmittance
all use the same 3σ-truncated kernel, so "exact" is exact-for-the-model and reconciles with the residual.

**S6. `Ch4:129–132` — the displayed inverse $t(\tau)$ omits its domain.** [verified] — `erf⁻¹` saturates
when $\mathrm{erf}(u_0)+\tau/C_k' > 1$ (remaining mass < τ); the code returns +∞ (escape), and this case
is exactly the per-primitive escape probability the argmin relies on.
Fix: add a one-line clause: "…where, if the argument exceeds 1, the primitive's remaining mass is below τ
and $t(\tau)=+\infty$ (the ray escapes this primitive)."

**S7. `Ch4:295–300` — the reference's $O(A^2)$ marcher complexity is asserted, not derived/measured.**
[verified] — it characterises an external implementation (Mitsuba volprim) that is not measured anywhere.
Fix: give a one-line derivation ("O(A) boundary updates over O(A) segments → O(A²) worst case") or hedge
("roughly $O(A^2)$").
