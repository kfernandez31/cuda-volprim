# G1 on RTX 4090 (Ada) — cross-architecture equal-quality vs Mitsuba, 2026-06-20

Cross-arch corroboration of the pinned 3090 ~59× headline, measured on a rented RTX 4090 (Ada, CC 8.9,
CUDA 13.2, driver 595.58). **Scoped to Ada; never folds into the 3090 headline.** Same scene/config as
G1 (cloud-meadow, scattering, σ=7.5, HG 0.85, 64 spp, 16 seeds, calibrated cloud caps 96/64, MIS), with
SER added for ours. Mitsuba = the *exact* build the 3090 used (mitsuba3 @ `7a16311a`, ellipsoids state,
cuda_ad_rgb) + volprim @ `622fabd`, both built from source on the box. k_clip999 + equal-quality math
identical to `run_g1_flat.sh` (radiance clipped at the 99.9th pct; speedup = (k_mits·t_mits)/(k_ours·t_ours)).
Times are steady-state render (ours "Total time"; Mitsuba `RENDER_TIME_S` with a warmup render so JIT/startup
is excluded — apples-to-apples). Data (gitignored): `results/campaign/g1_4090_seeds/`.

## Variance reproduces the 3090 EXACTLY (validates that only timing changed)
| arm | mean | k_raw | k_clip999 |
|---|---|---|---|
| ours-MIS (4090) | 0.3214 | 1.99 | 1.887 |
| ours-MIS (3090 banked) | 0.3214 | 1.99 | 1.887 |
| Mitsuba-analog (4090) | 0.3201 | 3898.6 | 110.59 |
| Mitsuba-analog (3090 banked) | 0.3201 | 3899 | 110.6 |

SER image identity vs no-SER: **PASS** (bit-identical). 0 cap overflows.

## Tier A — headline-comparable config (analytic, MIS) + SER
| config (4090, cloud-meadow, 64 spp) | render t_med | equal-quality vs Mitsuba-analog (clip / raw) |
|---|---|---|
| Mitsuba-analog (its only unbiased mode) | 4.347 s | — |
| ours, MIS, **no SER** | 3.285 s | **77.5×** / 2598× |
| ours, MIS, **+SER** | 2.309 s | **110.3×** / 3697× |

SER within ours = 1.423× (matches banked A/B 1.422×).

**Reading:** the same MIS estimator that gives ~59× on the 3090 gives **77.5×** on Ada (our megakernel
scales to the newer GPU better than Mitsuba's Dr.Jit pipeline; t_mits/t_ours rises from ~1.0 on the 3090
to 1.32), and SER lifts it to **110×** (t ratio 1.88). A divergence lever the reference's compiled
pipeline cannot use.

## Tier B/C — maximal configs (max_4090.sh, same Mitsuba ref reused)
Reuses the tier-A Mitsuba reference (k_clip=110.59, t=4.347s) — same scene/session. Only ours re-rendered
(16 seeds @64 spp, `--ris`). Builds: `max_unbiased` = caps+SER+fast-erf; `max_icos` = +`THESIS_ICOSPHERE=ON
THESIS_ICOSPHERE_N=2`. 0 overflows; icosphere compile confirmed (N=2).

| config (4090, cloud-meadow, 64 spp) | mean | k_clip999 | render t_med | equal-quality vs Mitsuba (clip / raw) |
|---|---|---|---|---|
| Mitsuba-analog | 0.3201 | 110.59 | 4.347 s | — |
| ours MIS+SER (tier A) | 0.3214 | 1.887 | 2.309 s | **110.3×** / 3697× |
| ours **RIS+fast-erf+SER** (maximal *unbiased*) | 0.3215 | 1.653 | 1.922 s | **151.3×** / 5191× |
| ours **+icosphere ℓ=2** (absolute max) | 0.3212 | 1.652 | 1.628 s | **178.7×** / 6132× |

Decomposition: SER 1.42× (A vs no-SER 77.5×); RIS+fast-erf 1.37× (A→B, matches documented ~1.48× RIS
equal-quality win); icosphere ℓ=2 1.18× raw (B→C, RT cores, k unchanged).

**Correctness caveat:** the icosphere arm's mean (0.3212) is **−0.09 %** vs analytic (0.3215) — ~9× the
1e-2 % validation gate, so tier C trades validation-grade exactness for speed (consistent with
\Cref{tab:icosphere}). Tiers A and B stay inside every gate (RIS mean ≈ MIS mean; the +0.4 % vs the
Mitsuba-analog GT is the documented overlap residual, not a new bias).

## Framing for the thesis
- Pinned headline stays **59× on the 3090** (validation-grade, MIS). Unchanged.
- Ada is a **scoped cross-arch probe** (§sec:ser, §5 setup). The defensible Ada number is **tier A: 110×**
  (same config + SER). Tier B (**151×**, maximal unbiased) and tier C (**179×**, absolute max, bias-flagged)
  are the achievable frontier — report with the validation caveat, never as the headline.
