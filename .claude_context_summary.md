# Session Summary: Fix Hit Buffer Numerical Precision Bug

## Problem Discovered
User ran new edge case tests (`hit_buffer_at_capacity`, `hit_buffer_overflow`) that exposed **critical numerical precision bug**:
- Tests create 256/300 overlapping Gaussians in a line (Z=1.0 to Z=128.5)
- Logs showed: `ERROR: optical_depth assertion would fail! t0=18.951582, t1=16.652035`
- **t0 > t1** (entry after exit!) → sentinel -420.0 → ray terminates prematurely
- Visual: Only ONE Gaussian visible instead of 256, black hole in center at high SPP

## Root Cause Analysis
**Original Architecture (Correct):**
- OptiX trace with backface culling → gives entry hits
- For each entry, compute exit analytically by re-intersecting from ray origin
- Check: `if (isect.t_exit > entry.t_hit)` then add exit to buffer

**The Bug:**
When rays travel 100+ units through 256 primitives:
1. OptiX reports entry at t=99.5 (hardware, robust)
2. Analytical re-intersection from ray origin (t=0):
   - Transform to local space: large values (~338 in local coords)
   - Solve sphere equation: catastrophic cancellation with large intermediate values
   - Result: `isect.t_exit = 99.32` (WRONG! Should be ~99.8)
3. Check fails: `99.32 <= 99.5` → exit NOT added
4. **Primitive lingers in active_prims forever** (no exit to remove it)
5. Later segments fail with `t0 > t1` errors

## Solution Implemented (sampling.cuh)
**Key Insight:** Compute exit from ENTRY POINT, not ray origin!

```cpp
// OLD (accumulates error over 100+ units):
auto isect = common::geometry::intersect_ellipsoid(ray, prim);
if (isect.is_hit() && isect.t_exit > entry.t_hit) { ... }

// NEW (only ~0.6 units, high precision):
const auto entry_point = ray.at(entry.t_hit);
const auto ray_from_entry = geometry::Ray::spawn(entry_point, ray.direction_);
auto isect_from_entry = common::geometry::intersect_ellipsoid(ray_from_entry, prim);

if (isect_from_entry.is_hit()) {
    const float exit_t = entry.t_hit + isect_from_entry.t_exit;  // Relative offset
    hit_buffer.emplace_back(exit_t, entry.prim_idx, true);
} else {
    printf("ERROR: intersection failed from entry point! This is a bug.\n");
    // Don't add exit - fail loudly, no dangerous fallback
}
```
